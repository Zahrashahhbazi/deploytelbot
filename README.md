# 🥇 ربات اعلان لحظه‌ای قیمت طلا

یک ربات تلگرامی ساده که قیمت لحظه‌ای **طلای ۱۸ عیار** (هر گرم، تومان) را از سایت `tgju.org` دریافت کرده و به چت(های) تلگرام شما ارسال می‌کند.

## ✨ قابلیت‌ها

- 📡 دریافت قیمت زنده طلای ۱۸ عیار از `tgju.org` (بدون نیاز به API Key)
- 📨 ارسال خودکار به یک یا چند چت/کانال تلگرام
- ⏱️ بازه زمانی قابل تنظیم (پیش‌فرض: هر ۶۰ ثانیه)
- 🚨 حالت هشدار آستانه‌ای (اختیاری): فقط وقتی قیمت از حداقل یا حداکثر تعیین‌شده عبور کند، پیام ارسال می‌شود
- 🔁 ارسال فقط در صورت تغییر قیمت (در حالت عادی، از ارسال پیام تکراری جلوگیری می‌شود)
- 🛑 خاموش شدن امن با `Ctrl+C`

## 📁 ساختار پروژه

```
.
├── main.py              # نقطه شروع برنامه
├── gold_price.py        # ماژول دریافت قیمت از tgju.org

├── setup_helper.py      # راه‌اندازی تعاملی (پیدا کردن Chat ID + ساخت .env)
├── requirements.txt     # وابستگی‌ها

├── .gitignore

```

## 🔧 نصب و راه‌اندازی

### ۱. کلون یا دانلود پروژه

```powershell
cd f:\pythone\phython1
```

### ۲. ساخت محیط مجازی (توصیه‌شده)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> اگه `Activate.ps1` ارور داد، اول این رو بزن:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```

### ۳. نصب وابستگی‌ها

```powershell
pip install -r requirements.txt
```

### ۴. ساخت ربات تلگرام 🤖

1. در تلگرام به **[@BotFather](https://t.me/BotFather)** پیام بدید.
2. دستور `/newbot` را بفرستید و مراحل را طی کنید.
3. **توکن** را کپی کنید (مثلاً `123456789:ABCdef...`).

### ۵. گرفتن Chat ID 🆔

**دو روش:**

#### 🔹 روش ۱ — راه‌اندازی خودکار با `setup_helper.py` (توصیه‌شده)
ابتدا **یک پیام** به ربات‌تان در تلگرام بفرستید (هر چیزی، مثلاً `سلام`)، سپس:
```powershell
.\.venv\Scripts\python.exe setup_helper.py
```
این اسکریپت:
- توکن را از شما می‌گیرد (مخفی وارد می‌شود)
- لیست چت‌هایی که به ربات پیام داده‌اند را نشان می‌دهد
- با انتخاب شما، فایل `.env` را آماده می‌کند

#### 🔹 روش ۲ — به‌صورت دستی
- **چت شخصی:** به **[@userinfobot](https://t.me/userinfobot)** پیام بدید و `Id` خود را کپی کنید.
- **گروه/کانال:** ربات را به گروه/کانال اضافه کنید، سپس با **[@RawDataBot](https://t.me/RawDataBot)** مقدار `chat.id` را بخوانید (برای کانال باید با `-100` شروع شود). ربات در کانال باید **ادمین** باشد.

### ۶. تنظیم فایل `.env` ⚙️

اگه `setup_helper.py` رو اجرا نکردید، دستی بسازید:

```powershell
Copy-Item .env.example .env
notepad .env
```

سپس مقادیر را ویرایش کنید:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdef_GhIjklMnOpQ
TELEGRAM_CHAT_IDS=123456789,-1001234567890
CHECK_INTERVAL=60

# اختیاری: فقط وقتی قیمت زیر ۵٬۰۰۰٬۰۰۰ یا بالای ۸٬۰۰۰٬۰۰۰ تومان رفت، هشدار بده
# GOLD_PRICE_MIN=5000000
# GOLD_PRICE_MAX=8000000
```

> 💡 برای ارسال به چند چت، شناسه‌ها را با کاما `,` جدا کنید.

### ۷. اجرا 🚀

```powershell
.\.venv\Scripts\python.exe main.py
```

برای توقف: **`Ctrl + C`** بزنید.

## ⚠️ نکات مهم

- **اتصال اینترنت پایدار** لازم است؛ اگر درخواست شکست بخورد، ربات در دور بعدی دوباره تلاش می‌کند.
- ساختار HTML سایت `tgju.org` ممکن است تغییر کند؛ در این صورت سلکتورهای موجود در `gold_price.py` باید به‌روزرسانی شوند.
- این ربات صرفاً یک ابزار اطلاع‌رسانی است و مسئولیتی در قبال تصمیمات مالی شما ندارد.

## 🩹 عیب‌یابی (Troubleshooting)

| مشکل | علت / راه‌حل |
|------|------|
| `ModuleNotFoundError: telegram` | `pip install -r requirements.txt` رو اجرا نکردی، یا `.\.venv\Scripts\python.exe` رو مستقیم اجرا نکردی |
| `401 Unauthorized` از تلگرام | توکن اشتباهه. دوباره از `@BotFather` با `/token` بگیر |
| `Chat not found` | Chat ID اشتباهه. ربات رو به گروه/کانال اضافه نکردی، یا برای کانال ربات رو **ادمین** نکردی |
| `Network error: ... proxy ...` | فیلترشکن سیستمی روشن نیست یا خاموش و روشن شده. فیلترشکنت رو چک کن و دوباره اجرا کن |
| قیمت برنمی‌گرده ولی خطا هم نمیده | ساختار سایت `tgju.org` عوض شده؛ سلکتورهای CSS در `gold_price.py` رو با لاگ‌های صفحه چک کن |
| ارورهای `SSL: WRONG_VERSION_NUMBER` | پروکسی سیستمی HTTP هست ولی پایتون داره سعی می‌کنه HTTPS بزنه. کد به‌صورت خودکار با `http://` بهش وصل میشه، ولی اگه مشکل ادامه داشت فیلترشکن رو عوض کن |
| `python: command not found` | پایتون نصب نیست. از [python.org](https://www.python.org/downloads/) دانلود و نصب کن |
| `Activate.ps1 cannot be loaded` (PowerShell) | `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` رو اجرا کن |

### تست سریع بدون تلگرام

```powershell

```
